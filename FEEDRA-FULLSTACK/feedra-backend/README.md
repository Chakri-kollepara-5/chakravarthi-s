🛠️ Feedra Backend
Production-grade backend for FeedraBite — an AI-powered food redistribution platform that connects surplus food providers with NGOs and communities.
This backend is built with Node.js + Express, secured using Firebase Authentication (Admin SDK), and deployed on Render. It serves as the single source of truth for business logic, authorization, and data aggregation.
